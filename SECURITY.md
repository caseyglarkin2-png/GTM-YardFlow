# Security Policy

## Supported Versions

- `main` branch: actively supported and receives security fixes.
- All other branches: not supported for security fixes.

## Reporting a Vulnerability

- Email: security@yardflow.com
- Please include a clear description, reproduction steps, and impact.
- You should receive acknowledgement within 72 hours. If you do not, please follow up on the same thread.

## Handling Process

1. We will triage reports and assess severity.
2. Fixes are developed and tested in a private branch.
3. Coordinated disclosure: we ship a fix before public disclosure whenever possible.
